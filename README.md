# Rohit Yadav — AI/ML Portfolio

A responsive, static portfolio website with no build step or paid dependencies.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. The resume is bundled at `assets/Rohit_CV.pdf`.

## Publish it free with GitHub Pages
1. Create a new **public** repository on GitHub, for example `rohit-ai-portfolio`.
2. Upload `index.html`, `README.md`, and the `assets` folder (keep the folder structure).
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site; the public URL will appear in Settings → Pages.

## Important before sending to recruiters
- The project cards link to the GitHub profile because individual repository URLs were not verified. Replace each link with the exact public repository URL if available.
- The project results are taken from the supplied resume. Be ready to explain how each metric was measured.
- This package is website-ready, but it is not online until you publish it to a hosting service.
- Keep your resume current and only share public code you are allowed to disclose.
